## 0. 確定した方針

| # | 項目 | 決定内容 |
|---|---|---|
| 1 | 配置 | 各チーム2体。自治体Aは奥の段、自治体Bは手前の段。それぞれ前衛列か後衛列を選ぶ（4パターン） |

## 1. 配置

### 1.1 位置

```
        味方                         相手
   後衛列   前衛列              前衛列   後衛列
 ① A奥    ② A奥        |      ② A奥    ① A奥     ← 奥の段（小さく・上）
 ③ B手前  ④ B手前      |      ④ B手前  ③ B手前   ← 手前の段（大きく・下）
```

- 自治体A＝奥の段（①か②）、自治体B＝手前の段（③か④）。
- ドラフト後の配置画面で、AとBそれぞれについて前衛・後衛を選ぶ。組み合わせは4通り（両方前衛／両方後衛／Aだけ前衛／Bだけ前衛）。
- 描く順番は「奥の段 → 手前の段」。重なったときは手前の段が上に来る。

### 1.2 座標（1000×560、暫定）

| 位置（v0.6.1で調整、Canvasは1000×640） | 味方 x | 相手 x | y | 縮尺 |
|---|---|---|---|---|
| 奥・後衛（①） | 165 | 835 | 270 | 0.85 |
| 奥・前衛（②） | 330 | 670 | 270 | 0.85 |
| 手前・後衛（③） | 160 | 840 | 440 | 1.15 |
| 手前・前衛（④） | 345 | 655 | 440 | 1.15 |

- 形の基準半径は現在の56から約95へ（約1.7倍）。面積による大きさ係数（0.72〜1.32倍）は継続。
- HPバー・名前・盾の輪は、重なっても読めるように少し外側へずらす。数値は実装時に調整。

### 1.3 狙われ方と前衛・後衛の違い

| | 前衛 | 後衛 |
|---|---|---|
| 狙われやすさ | 重み7 | 重み3 |
| 通常攻撃 | 体当たり（近接）・威力1.0倍 | 弾（遠距離）・威力0.8倍 |

- 生き残っている敵の重みで抽選する。2体が同じ列なら半々。1体だけなら必ずその1体。
- 「長老の狙撃」だけは例外で、後衛を優先して狙う（後衛がいなければ前衛）。
- 倒れた自治体は消え、残った1体は位置を動かない。

## 2. 三すくみ（属性）

### 2.1 決め方

県内の人口密度の順位で、上から3等分する。

| 属性 | 決め方 | 戦い方 |
|---|---|---|
| 都会 | 人口密度が県内上位1/3 | 攻撃型 |
| 郊外 | 人口密度が県内中位1/3 | 支援型 |
| 田舎 | 人口密度が県内下位1/3 | 自然・魔法型 |

### 2.2 相性

**都会 → 郊外 → 田舎 → 都会**（矢印の先に強い）

| 有利 | 理由づけ |
|---|---|
| 都会は郊外に強い | 都会は通勤・買い物で郊外の人を引き寄せる |
| 郊外は田舎に強い | 郊外は田舎から若い世代を呼び込む |
| 田舎は都会に強い | 田舎の自然と食が都会の人を癒やす |

- 有利な相手へのダメージ：**1.3倍**
- 不利な相手へのダメージ：**0.8倍**
- 同じ属性どうし：1.0倍
- 回復・補助には相性をかけない。

## 3. 技

### 3.1 名前のルール（A案）

| 種類 | 名前の終わり方 | 色・アイコン |
|---|---|---|
| 攻撃 | 「〜撃」 | 赤 ⚔ |
| 回復 | 「〜の癒し」 | 緑 ✚ |
| 補助 | 「〜の加護」 | 青 🛡 |

カード・相手チーム表示・技の発動表示に、色とアイコンを必ず添える。

### 3.2 決め方

1. 県内で人口1位 → 「県都の加護」
2. 県内で面積1位 → 「大地の加護」（人口1位と同じ自治体なら、面積2位に回す）
3. それ以外 → 属性グループの中で、高齢化率の順位をさらに3等分（若い・中間・高齢）して決める

### 3.3 技の一覧（効果の数値は暫定）

| 属性 | 区分 | 技 | 種類 | 効果 |
|---|---|---|---|---|
| 特別 | 人口1位 | 県都の加護 | 補助 | 味方2体の攻撃力+25%（10秒） |
| 特別 | 面積1位 | 大地の加護 | 補助 | 自分に盾30（8秒）。盾がある間、攻撃されたら受けたダメージの50%を反撃 |
| 都会 | 若い | ベッドタウン連撃 | 攻撃 | 敵2体にそれぞれ ATK×1.0 |
| 都会 | 中間 | 衛星都市の追撃 | 攻撃 | 単体に ATK×1.3。直後に相方の行動ゲージを満タンにする |
| 都会 | 高齢 | 下町の加護 | 補助 | 味方2体の受けるダメージ−30%（8秒） |
| 郊外 | 若い | 子育て世代の加護 | 補助 | 味方2体の行動ゲージ+50 |
| 郊外 | 中間 | 田園の癒し | 回復 | 味方2体をそれぞれ 18×MAG/100 回復 |
| 郊外 | 高齢 | 長寿の癒し | 回復 | 自分を 20×MAG/100 回復。15秒間、一度だけHP1で踏みとどまる |
| 田舎 | 若い | 森の加護 | 補助 | 味方2体に盾16（8秒） |

- 盾・強化・弱体は同じ種類を重ねがけしない。かけ直したときは効果時間だけ延長する（v0.4.2の盾ルールと同じ考え方）。
- 補助技も、効果がまだ十分残っているときは使わずにSPを温存する（v0.4.2のF05と同じ考え方）。

## 4. データ

- **人口・65歳以上・75歳以上**：総務省「住民基本台帳に基づく人口、人口動態及び世帯数」年齢階級別人口（市区町村別）。全国分が1ファイルにまとまっている。
- **面積**：国土地理院「全国都道府県市区町村別面積調」。
- **人口密度**：上の人口÷面積で計算する。
- **形**：国土数値情報（行政区域データ）の簡素化版（smartnews-smri/japan-topography）。
- 福岡県版も、県の資料（2026年4月）から上の全国データに切り替える。出典と時点を全県でそろえるため。
- 政令市は区を合計して市単位にする。郡名は表示名から外す（例：「球磨郡五木村」→「五木村」）。
- 境界の一部が決まっていない市町村は、面積が参考値であることを出典欄に書く。
- 能力値（HP・攻撃・防御・速さ・魔力）の計算式は現行のまま。県をまたいでも同じ式を使う。

### 4.1 画面での見せ方

- カードに属性（都会／郊外／田舎）と技の種類アイコンを表示する。
- 「県内で人口密度◯位」も表示し、「町なのに都会？」と感じたときに理由が分かるようにする。
